  - impeccable
  总控/入口类能力，建议选
  - audit
  先查问题，适合第一步审计现有页面
  - critique
  偏设计视角点评，适合找“哪里土、哪里平、哪里不高级”
  - polish
  做精修，很适合你现在“升级页面质感”
  - layout
  调整页面结构、信息层级、留白
  - typeset
  调整排版、字体、段落层级
  - optimize
  做质量优化，通常也适合顺手清理一些界面实现问题
  - shape
  对组件轮廓、卡片、按钮、面板气质有帮助

  可选

  - adapt
  如果你想顺带把移动端 / 小屏适配一起考虑，就加上

    ---
  暂时不建议第一批选

  这些不是不能装，而是现在优先级没那么高：

  - animate：动画优先级低
  - bolder / quieter：偏风格强弱调节，后面再说
  - colorize：先别急着大动配色
  - delight：偏“加趣味感”
  - distill：偏极简收敛
  - clarify：更偏文案/表达清晰
  - overdrive：力度可能太大，容易改过头
